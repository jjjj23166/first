# 前哨工兵队 / Zombie RTS Outpost

单文件 HTML + Canvas 即时战略游戏，支持电脑及手机触屏操作。本仓库包含最新的战术、策略和新兵种版本。

## 下载到电脑桌面

1. 点击本页绿色 **Code** 按钮 → **Download ZIP**。
2. 将 ZIP 保存到桌面，右键 → **全部提取**。
3. 打开解压后的文件夹，双击 **开始游戏.html**，使用 Chrome、Edge 或 Firefox 打开。

请先完整解压，不要在压缩软件预览中启动。游戏无需安装 Node.js 或游戏引擎。

这是网页源码包，不是 Android APK，也尚未配置在线试玩。部分手机文件管理器不能直接运行本地 HTML；手机浏览器可通过另行部署的静态网站访问。推荐横屏。

## 新增内容

- 触屏点选与移动、镜头拖动、双指缩放、框选和编队按钮。
- 巡逻、攻击移动、停止，以及兵营/指挥中心集结点。
- 均衡、突击、防守姿态；防御建筑目标优先级；消耗资源并有冷却的紧急维修。
- 狙击兵、医疗兵、盾卫；迫击炮阵地、维修工坊。

新兵和新建筑入口在战场底部 **战略** 面板：先选兵营再训练，或选择建筑图纸后点地图放置。

详细说明见 [新兵种与建筑](新兵种与建筑.md)、[策略升级说明](策略升级说明.md) 和 [战术操作说明](战术操作说明.md)。原始 `说明.md` 保留旧版本介绍，其中历史测试通过记录不代表本次全部重新执行。

## 开发与验证

不需要构建步骤。从仓库根目录启动本地服务：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

通过本地浏览器访问 `/game/index.html`。新增测试需要 Node.js 22+ 及 Chromium / Edge：

```sh
node tests/qa-reinforcements.js
node tests/qa-strategy.js
node tests/qa-tactics.js
node tests/qa-mobile.js
```

以上各套件单独运行，先保持 HTTP 服务运行。`ZRTS_BROWSER` 指定浏览器路径，`ZRTS_BASE_URL` 指定本地服务地址。仅在隔离 Linux 容器必要时使用 `ZRTS_NO_SANDBOX=1`。

最新一轮执行并通过：新增兵种/建筑 14 项、策略 19 项、触控模拟 7 项，以及适配后的旧核心循环 7 项和克制/经济系统 19 项。部分原始旧测试仍保留 Windows 浏览器和打包前路径，不能直接跨平台运行。

尚未验证 Android/iPhone 真机与长期对局平衡。部分兵种、建筑复用基础造型，使用独立文字标记区分。战场保留原有 4:3 布局，小屏文字仍待优化。
